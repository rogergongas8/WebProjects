Prompt C — Video Transition

Two options: use C1 if you generated A & B images, or use C2 to skip straight to video with no images needed.

Upload Prompt A as your start frame and Prompt B as your end frame, then paste this as the motion prompt.

Starting from the fully assembled modern house [reference Prompt A image], animate a smooth architectural deconstruction. Motion: the building separates layer by layer from the top down — roof membrane peels away first and floats upward, then roof trusses drift apart, then exterior wall panels slide outward in all four directions, then interior partitions and floor slabs drop downward in sequence, finally the foundation slab stays anchored at center. All components drift to floating, evenly spaced final positions matching the exploded view [reference Prompt B image]. Cinematic architectural CGI aesthetic, pure white background throughout, no camera movement, smooth ease-out on all components. Compatible with: Runway Gen-3, Kling, Pika, Higgsfield.

Tips

  • Generate Prompt A first — then reference it explicitly when generating Prompt B for visual consistency across shots.
  • The reverse animation (components assembling into the house) is often more compelling. Ask the video model for both directions and compare.
  • For Runway Gen-3: upload Prompt A as the keyframe image and paste Prompt C as the text prompt.
  • Midjourney works best for A and B. Kling or Runway Gen-3 for C. Pika handles shorter clips well.
  • Add "architectural visualization, unreal engine 5" to Prompt A for a more photorealistic 3D render feel.
