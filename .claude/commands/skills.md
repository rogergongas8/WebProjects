# Skill Picker

Read the task description and apply the most appropriate skill from the options below. Do not ask for confirmation — just pick and apply.

## Decision Guide

### What are you building?

**New UI from scratch (React / Next.js / Tailwind)**
→ Use `design-taste-frontend` — the default high-quality frontend skill with configurable design dials (variance, motion, density). Best all-around choice for new components or pages.

**Need it to look like a $150k agency site (Awwwards-tier)**
→ Use `high-end-visual-design` — double-bezel components, spring physics, asymmetric layouts, cinematic motion. For when standard good isn't enough.

**Clean, editorial, Notion/Linear-style interface**
→ Use `minimalist-ui` — warm monochrome, flat bento grids, editorial typography, zero gradients. When "less is more" is the brief.

**Raw, mechanical, data-heavy or portfolio with attitude**
→ Use `industrial-brutalist-ui` — Swiss typography meets military terminal. Rigid grids, CRT effects, extreme type contrast. For projects that need to feel like a declassified blueprint.

**Upgrading or fixing an existing project**
→ Use `redesign-existing-projects` — audits the current code, identifies generic AI patterns, applies targeted premium upgrades without breaking anything.

**Generating a DESIGN.md for Google Stitch**
→ Use `stitch-design-taste` — outputs a semantic design system file optimized for Stitch's AI agent.

**Building a scroll-driven video animation site (Apple-style)**
→ Use `scroll-stop-builder` — full interview + builds the HTML file. Requires FFmpeg and a video file.

**Need AI image/video prompts for product animations**
→ Use `scroll-stop-prompter` — generates 3 coordinated prompts (assembled, deconstructed, video transition) with a copy-ready HTML viewer.

**Output keeps getting truncated or shortened**
→ Add `full-output-enforcement` to any prompt — bans all truncation patterns and forces complete output.

**Creating or improving a skill**
→ Use `skill-creator` — full loop from drafting to benchmarking.
