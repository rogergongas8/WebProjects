# High-End Visual Design

**Command:** `/high-end-visual-design`
**Source:** [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)

## What It Does

Awwwards/Linear-tier agency design. Generates $150k+ agency-level digital experiences with haptic depth, cinematic spatial rhythm, obsessive micro-interactions, and flawless fluid motion. Never generates the same layout twice.

## Variance Engine (Auto-Selected Per Generation)

### Vibe Archetypes (picks one)
- **Ethereal Glass** — OLED black, radial mesh gradients, vantablack cards with backdrop blur
- **Editorial Luxury** — Warm creams, variable serif fonts, CSS film-grain overlay
- **Soft Structuralism** — Silver-grey/white, massive bold Grotesk, floating ambient shadows

### Layout Archetypes (picks one)
- **Asymmetrical Bento** — Masonry-like CSS Grid with varying card sizes
- **Z-Axis Cascade** — Cards stacked like physical objects with depth and slight rotation
- **Editorial Split** — Massive typography left, interactive content right

## Signature Techniques

- **Double-Bezel (Doppelrand):** Nested outer shell + inner core for all cards — looks like machined hardware
- **Button-in-Button:** Arrow icons always nested in their own circular wrapper inside the button
- **Fluid Island Nav:** Floating glass pill navbar that morphs to full-screen overlay on open
- **Magnetic Button Physics:** Buttons scale down on click, inner icon translates diagonally
- **Scroll Entry:** Elements fade up with blur from `translate-y-16 blur-md opacity-0`

## Banned Patterns

- Fonts: Inter, Roboto, Arial, Open Sans, Helvetica
- Icons: Thick Lucide, FontAwesome, Material Icons
- Shadows: Generic 1px gray borders, harsh dark drop shadows
- Layouts: Edge-to-edge sticky navbars, symmetrical Bootstrap grids
- Motion: Linear or ease-in-out transitions

## When to Use

Landing pages, portfolios, and marketing sites where you want maximum visual impact and premium feel.
